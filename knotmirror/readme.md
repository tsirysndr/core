# KnotMirror

KnotMirror is a git mirror service for all known repos. Heavily inspired by [indigo/relay] and [indigo/tap].

KnotMirror syncs repo list using tap and subscribe to all known knots as KnotStream.

[indigo/relay]: https://github.com/bluesky-social/indigo/tree/main/cmd/relay
[indigo/tap]: https://github.com/bluesky-social/indigo/tree/main/cmd/tap
